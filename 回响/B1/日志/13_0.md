# 0x08

……听得到吗？听——得——到——吗——？

嗯，好，看来状态还不错。

那么，我想想……哦，应该先自我介绍一下。

锵锵！这里是夏榕，第二扇区的代表人，在过去一段时间里主要忙于一些资料的修订工作。

虽然本来打算问第一扇区要一个单独的媒介，不过那家伙说“对你来说有这个用就不错了”，那好吧……反正一号两用会受影响的又不是我:P

虽然本来想和你们——嗯，就是第一扇区有时候会称作“探寻者”的那些人里的一部分——亲自见面，不过，第一扇区近些年来招进来的人实在少得可怜，所以我也只好退而求其次，用这种方式和你们交流了。

不过，虽说是要“交流”，我一时还真没想好该说些什么……有什么是我现在能和你们聊聊看的呢？如果要讲那些“不够常识的常识”，你们好像已经读过指南了（欸，把指南放在那里的人好像也是我自己，嗯……）；如果要讲历史的话，感觉最后又会讲成一堆让人不明所以的谜语；如果讲故事……啊，这个说不好可以哦？不过，如果故事稍长一些的话，用现在这种媒介好像又不太合适……

嗯，那就先让我来坑害第一扇区一把吧（笑）。据我所知，你们大概有不少问题，而第一扇区应该是不会回答的，对吧？虽然我知道的也有限，不过，你们有什么想问的，都可以试着问问看。我会尽量给出答案……希望我不会因此被吊起来拷打（不是）。

总之，就先这样—— #
